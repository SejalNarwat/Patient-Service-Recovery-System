ℹ️ Agent Descriptions

1. Data Preparation Agent

Scans all 40 records for missing fields, duplicate IDs, and suspiciously short text. Tags each record with quality flags.

2. Feedback Analysis Agent

Classifies feedback into 8 categories, detects sentiment, extracts themes, and generates a concise summary. IBM Granite enhances summaries when available.

3. Risk Identification Agent

Flags safety concerns, repeated failures, ambiguous feedback, and high-impact service failures. Triggers escalation for Critical/High risks.

4. Prioritisation Agent

Scores each case P1–P4 using risk level, department criticality, sentiment, and keyword boosters. Provides transparent rationale for every score.

5. Recovery Planning Agent

Generates empathetic, department-specific recovery actions with responsible roles, follow-up steps, and timelines. IBM Granite personalises empathy statements.

Human Review (HITL)

All plans are held in Pending Review until a human reviewer approves, rejects, or modifies them. No action proceeds without human sign-off.
